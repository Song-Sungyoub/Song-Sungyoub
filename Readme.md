## 도구와 개발 예제

직접 만든 도구와 공개한 개발 코드를 모았습니다.

### 데스크톱 도구

| 도구 | 용도 | 바로가기 |
| --- | --- | --- |
| **InerConfig** | JSON · XML · CSV · YAML · INI 설정 파일을 편집하는 Windows 도구 | [다운로드](https://github.com/Song-Sungyoub/iner-config/releases/latest) · [소스](https://github.com/Song-Sungyoub/iner-config) |
| **InerMD** | 수식과 다이어그램을 지원하는 Windows Markdown 리더·편집기 | [빌드 방법](https://github.com/Song-Sungyoub/iner-md#%EA%B0%9C%EB%B0%9C) · [소스](https://github.com/Song-Sungyoub/iner-md) |

### 라이브러리 · 예제

| 코드 | 용도 | 바로가기 |
| --- | --- | --- |
| **SignalR Library** | .NET Framework 4.8용 ASP.NET SignalR 2 클라이언트·자체 호스팅 서버 관리 | [사용 예제](https://github.com/Song-Sungyoub/dotnet-framework-signalr#usage) · [소스](https://github.com/Song-Sungyoub/dotnet-framework-signalr) |
| **WPF Satellite Tracking** | WPF Viewport3D 기반 위성 궤도·지상국 안테나 추적 데모 (.NET 9) | [실행 방법](https://github.com/Song-Sungyoub/wpf-satellite-tracking#build) · [소스](https://github.com/Song-Sungyoub/wpf-satellite-tracking) |

InerConfig는 설치 파일을 제공합니다. 나머지 항목은 소스에서 빌드하며, 실행 환경과 사용 조건은 각 저장소의 문서를 참고해 주세요.
